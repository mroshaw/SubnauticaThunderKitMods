# Cuddlefish Recall

Lost your precious Cuddlefish? No problem, the Cuddlefish Recall mod is here to help!

## **Features**

- Bring all of your spawned Cuddlefish to your location at the press of a button.
- The mod can be configured to instantly teleport Cuddlefish, or set them swimming naturally to their destination.
- Cuddlefish locations and distances, while being recalled, are shown in the HUD UI.
- Constantly tops up all of your Cuddlefish's health, just to keep them safe and sound!
- Feeding your Cuddlefish treats fully restores its health.
- Configuration can be tweaked via the Options > Mods menu.
- Key bindings can be changed in Options > Mod Input menu.

## **User Guide**

- Recalling Cuddlefish is activated using the keyboard or controller. You can customise the key and controller bindings via the Options > Mod Input menu.
- To recall your Cuddlefish, **hold <ctrl> and press the recall key or button binding**.
- This is defaulted to the **"r" key** on the keyboard.
- To cancel all active recalls, **hold <shift>, <ctrl>, and press the recall key or button**.
- There is no controller button binding by default.

## Installation and Dependencies

> ***IMPORTANT!** This mod uses **BepInEx** ﻿﻿and **Nautilus**﻿﻿. You **must** install the latest versions of these to use this mod. As the 2025 patch broke a lot of mods, you must use **Nautilus version 1.0.0-pre.50** or later.*
