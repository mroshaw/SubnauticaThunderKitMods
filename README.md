# Subnautica ThunderKit Mods

## Introduction

This repository contains all of my Subnautica [ThunderKit](https://github.com/PassivePicasso/ThunderKit) Mods in a single Unity 2019.4.36f1 project. It includes the mods themselves, and high level ThunderKit settings and extensions, as well as Unity helpers and utilities.

I also maintain an equivalent [Subnautica: Below Zero repository](https://github.com/mroshaw/SubnauticaThunderKitMods/), with ThunderKit mods for the Subnautica: Below Zero game.

You can find non-ThunderKit Subnautica mods in my [Subnautica Mods](https://github.com/mroshaw/SubnauticaMods) repository, though these will be migrated over time to this new repo.

## Mods

- [Subnautica Pets SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/SubnauticaPets2_SN) - adds craftable creatures to the game via new game lore, fragments, resources and base parts.
- [Cuddlefish Recall SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/CuddlefishRecall_SN) - adds a keyboard shortcut to call a friendly Cuddlefish to the player's location
- [Subnautica Cheater SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/SubnauticaCheater_SN) - adds cheats for infinite oxygen and health, mainly for use in debugging and testing other mods.

## Make your own mods

If you're interested in making your own mods for the Subnautica games, check out my [Beginners Guide to Modding Subnautica](https://mroshaw.github.io/Subnautica/). There's a section in here too for [setting up and using ThunderKit](https://mroshaw.github.io/Subnautica/moddingwiththunderkit.html) with the Subnautica games.
