# Save My Eyes: Ultimate Edition SN

This mod provides settings and toggles for players with photosensitivity. It's a combination and continuation of the excellent "Save My Eyes" series of mods produced by author **kelsarhu**.

It is with the explicit permission of **kelsarhu** that I've reproduced and enhanced functionality from their original mods to create this new, Ultimate Edition.

## Features

This mod provides a number of configurable features that are designed to reduce the impact of visual effects on players with photosensitivity. All features can be toggle on and off, and the strength of many of the features can be configured using the mod option sliders.

- Flare light intensity
- Targeted light intensity, currently including the Laser Cutter
- Targeted material emission, currently including laser-cut doors
- Independent particle amount, size, speed and brightness controls for supported effects
- Targeted trail and line intensity for Laser Cutter and laser-cut door effects
- Water Filtration Machine beam suppression

Effects are added deliberately for specific objects and actions. Shared settings are applied only to supported targets, avoiding unintended changes to unrelated environmental lighting and visual effects.



## Installation and Dependencies

> ***IMPORTANT!** This mod uses **BepInEx** ﻿﻿and **Nautilus**﻿﻿. You **must** install the latest versions of these to use this mod. As the 2025 patch broke a lot of mods, you must use **Nautilus version 1.0.0-pre.50** or later.*
