# Subnautica Pets 2

## Help!

If you're stuck in "Adventure" mode, here are some hints and tips:

## DNA Resources

You can scan for Pet DNA via a Scanner Room. Upgrade the range and don't forget to craft and equip a Scanning Chip so you can track down DNA resources via your HUD.

If you're really stuck, you can use console commands to spawn DNA in your inventory:

```
item AlienRobotPetDna 5
item BloodCrawlerPetDna 5
item CaveCrawlerPetDna 5
item CrabSquidPetDna 5
item CatPetDna 5
```
