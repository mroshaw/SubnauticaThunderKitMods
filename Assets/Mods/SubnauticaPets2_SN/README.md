## Installation and Dependencies

> **IMPORTANT!** This mod uses **BepInEx** ﻿﻿and **Nautilus**﻿﻿. You **must** install the latest versions of these to use this mod. As the 2025 patch broke a lot of mods, you must use **Nautilus version 1.0.0-pre.50** or later.

> ﻿**REALLY IMPORTANT!** Because the mod spawns new collectable resources, **you must start the mod in a new game**. I'm really sorry, but this is a limitation of the Subnautica spawning system, where resources are spawned and persisted during gameplay. 

## **User Guide**

With this new Subnautica Pets mod, I've rebuilt from the ground up, introducing "lore-friendly" gameplay around the “Pets” concept. With this in mind, this mod is ideally played "as is", with discovery playing a part in getting the most out of the mod. As such, I recommend you play the mod in "Adventure" mode! When it comes to collecting resources, don't forget the Scanner Room and Scanner Room Chip - scanning for resources is your friend!

That said, if you're in the end game and just want to enjoy having some beasties running around your base, you can enable "Creative" mode in the mod options to unlock everything. All you need then is titanium, and you can explore all the mod has to offer. Switching modes requires a restart of the game, but can be done mid-save.

Note that "Custom Pets" don't require DNA, and are not a part of the "Adventure" lore-friendly experience.

Unlike previous versions, there are no other “mod options” or keyboard shortcuts. All mod functionality is built into the game.

## **Spoilers**

This new version of the Pets mod has been created in a way to make the experience more "organic", with discovery and task/reward-focused gameplay, rather than "instant access" to pets. If you want to get straight to spawning Pets, you can find spoilers on how it all works [here](https://github.com/mroshaw/SubnauticaThunderKitMods/blob/main/Assets/SubnauticaPets2_SN/readme.md) or simply enable "Creative" mode, save, quit, reload, and enjoy! You can spawn DNA via the console using the standard "item" command - just use these item names in your command:

- AlienRobotPetDna
- BloodCrawlerPetDna
- CaveCrawlerPetDna
- CrabSquidPetDna
- CatPetDna
