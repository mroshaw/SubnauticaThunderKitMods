# Subnautica ThunderKit Mods

## Introduction

This repository contains all of my Subnautica [ThunderKit](https://github.com/PassivePicasso/ThunderKit) Mods in a single Unity 2019.4.36f1 project. It includes the mods themselves, and high level ThunderKit settings and extensions, as well as Unity helpers and utilities.

I also maintain an equivalent [Subnautica: Below Zero repository](https://github.com/mroshaw/SubnauticaThunderKitMods/), with ThunderKit mods for the Subnautica: Below Zero game.

## Mods

- [Aqua Eclipse Now SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/AquaEclipseNow_SN) - adds new console commands to force a solar eclipse to occur.
- [Auto Locker Labels SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/AutoLockerLabels_SN) - dynamic labels for lockers, based on their contents.
- [CuddleCam SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/CuddleCam_SN) - adds remote viewing screens to see through the eyes of your Cuddlefish.
- [Cuddlefish Recall SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/CuddlefishRecall_SN) - adds a keyboard shortcut to call a friendly Cuddlefish to the player's location.
- [More Aquariums SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/MoreAquariums_SN) - adds new buildable aquariums to the habitat builder, and a custom fish movement component.
- [Save My Eyes: Ultimate Edition SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/SaveMyEyesUltimateEdition_SN) - adds QoL features for players with photosensitivity and light sensitivity.
- [Startup Commands SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/StartupCommands_SN) - allow players to configure a list of console commands to run every time the game is started.
- [Subnautica Cheater SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/SubnauticaCheater_SN) - adds cheats for infinite oxygen and health, mainly for use in debugging and testing other mods.
- [Subnautica Pets SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/SubnauticaPets2_SN) - adds craftable creatures to the game via new game lore, fragments, resources and base parts.
- [Tame Creatures SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/TameCreatures_SN) - selectively remove aggressive behaviours from various creatures in the game.
- [Vehicle Enhancements SN](https://github.com/mroshaw/SubnauticaThunderKitMods/tree/main/Assets/Mods/VehicleEnhancements_SN) - adds configurable HUD elements, such as a speedometer and HSI, to all vehicles in the game.
